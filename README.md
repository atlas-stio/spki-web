## 项目概述

PKI 证书系统。

## 技术栈

- **核心框架**：Vue.js 3
- **构建工具**：Vite
- **路由管理**：Vue Router
- **UI 组件库**：Element Plus
- **HTTP 客户端**：Axios
- **样式预处理器**：Sass / Less
- **代码规范**：ESLint + Prettier
- **版本控制**：Git

## 项目结构

```
spki
```

## 快速开始

### 环境要求

- Node.js v24.x
- npm v11.x

### 安装依赖

```
# 使用npm
npm install
```

### 创建环境变量文件

```
echo "VITE_API_Endpoint=https://api.example.vmlocal:33860/" > .env.local
```

### 开发环境运行

```
# 使用npm
npm run dev
```

### 构建生产环境

```
# 使用npm
npm run build
```
